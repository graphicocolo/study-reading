# コードリーディング用コードの出力のための指示

「TypeScript で〇〇を実装したコードを書いて」と依頼し、そのコードを読解素材にする。

```text
コードリーディングの練習用に、TypeScript のコードを1ファイル生成してください。

学習フェーズ：studyloadmap.md の 🔥 マークの項目まで学習を進めています
条件：
- 50〜100行程度（多すぎず、少なすぎず）
- 実務に近いユースケース（バリデーション・データ変換・API通信など）
- コメントなし（自分で読解するため）
- 1つのファイルで完結する構成

生成後は読解を始めるので、説明は不要です。
```

毎週火曜の開始時にこのテンプレートをそのまま貼り付け、ユースケースだけ変えて使う。

テンプレートのポイントは3つです：

- 学習フェーズを自動参照 — studyloadmap.md の 🔥 マークを見て毎回AIに伝えれば、フェーズが進んでも使い続けられる
- コメントなし指定 — 最初から解説があると読解にならないため、意図的に外している
- ユースケースだけ変える — バリデーション・データ変換・API通信などを週ごとにローテーションすれば題材が尽きない
